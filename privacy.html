Privacy Policy

Last updated: October 2026

TikTok Cloud Downloader is a private personal automation tool.

Google Drive access

The application accesses Google Drive solely to upload, organize, and maintain media files and related state files created by the TikTok Cloud Downloader automation.

Use of Google user data

Google account data is used only as necessary to authenticate with Google Drive and perform the requested file operations.

Google user data is not sold, shared with advertisers, or used for advertising purposes.

Data storage

Files generated by the automation are stored in the owner's Google Drive account. OAuth credentials used by the automation are stored privately and are not intentionally shared with third parties.

Data sharing

The application does not intentionally share Google user data with third parties.

Revoking access

Access can be revoked at any time through the security settings of the connected Google account.

Contact

This application is operated for personal use by its owner.
